# CRM perso — téléchargements

Installateurs Windows de **CRM perso** (prospection, mails, tâches et suivi de projets).

👉 **[Télécharger la dernière version](https://github.com/nicolas-brault/crm-perso-releases/releases/latest)** : fichier `CRM-perso-Setup-x.y.z.exe`.

- Une fois installée, l'application se met à jour toute seule.
- L'installateur n'est pas signé : au premier lancement, Windows affiche « Windows a protégé votre ordinateur ». Cliquez sur **Informations complémentaires → Exécuter quand même**.

Ce dépôt ne contient que les installateurs, publiés automatiquement. Le code source est privé.
